# Millet&More — Millet & Healthy Snacks Store

A responsive, accessible multi-page HTML/CSS/JavaScript storefront concept showcasing air-roasted native millet snacks and pantry staples.

## Pages
- `index.html` / `Home1.html` — Editorial, product-led homepage (default landing page)
- `Home2.html` — Brand story & grain revolution alternative homepage with farm-to-crunch journey and nutritional matrix
- `products.html` / `shop.html` — Complete product catalogue with category filters, value bundles, and clean-ingredient guarantees
- `health-benefits.html` / `recipes.html` — Scientific supergrain health breakdown, clinical wellness goals, daily snacking routine, and recipes
- `about.html` — Brand roots, values, and women farmer collective partnership
- `contact.html` — Customer care details, store & product enquiry form, interactive FAQ accordion, and store location
- `login.html`, `register.html` — Authentication screens with password eye toggle, social login options, and terms validation

## Key Features
- **Responsive Navigation**: Full desktop nav with distinct active page highlights in both light and dark themes; hamburger drawer on screens `<= 1024px`
- **Theme & RTL Support**: Real-time theme toggle (light/dark) and RTL mode with saved `localStorage` preferences
- **Visual Contrast**: Strict dark-theme contrast rules ensuring dark typography and icons on light-green backgrounds
- **Interactive Storefront**: Live basket counter, animated notifications, tab filtering, FAQ accordions, password visibility toggles, and smooth scroll back-to-top button
- **High Performance & Zero Build Step**: Pure semantic HTML5, modern vanilla CSS3, and lightweight JavaScript; optimized for GitHub Pages with `.nojekyll`
